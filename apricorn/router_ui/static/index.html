Project Apricorn

STGNN PCB Routing Intelligence

A pure-software Python/PyTorch/TypeScript routing system that uses Spatio-Temporal Graph Neural Networks (STGNN) and Wavefront A* for efficient, DRC-clean PCB routing with an interactive web visualizer.

🖧
How It Works
1
Graph & DRC
Parse board → Build graph → DRC engine
➔
2
STGNN Prediction
Edge costs → Net priorities
➔
3
Routing & Visualization
Wavefront A* → Rip-up & Re-route → Web UI
Key Features
✔Pure software (Python / PyTorch / TypeScript)
✔STGNN for edge costs and net priorities
✔Negotiated Wavefront A* routing with 45° bend penalties
✔3D / 2D interactive web visualizer with layer toggling
✔Pure geometric DRC verification and violation reporting
✔Supports multi-layer PCB boards
Tech Stack
🐍 Python 3.11+ 🔥 PyTorch ⚡ FastAPI 📘 TypeScript 🎮 Three.js / Canvas ⚛️ React (Optional UI)
